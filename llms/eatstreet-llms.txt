# EatStreet

> EatStreet is a Madison, Wisconsin online food ordering and delivery marketplace
> connecting diners with local restaurants for takeout and delivery across US
> college towns and midsize metros. It ran a documented public API through 2019;
> that surface has since been retired and its developer portal removed. The live
> API is an OAuth 2.0 protected v2 service on the consumer host, discoverable only
> through the RFC 8414 authorization server metadata EatStreet still publishes.

Generated by API Evangelist from public sources on 2026-08-12. EatStreet does not
publish an llms.txt; https://eatstreet.com/llms.txt returns the site's single-page
app HTML shell, not a document.

## API surface

- [EatStreet API v2](https://eatstreet.com/api/v2): Live OAuth 2.0 protected API on
  the consumer host. Only the OAuth endpoints are publicly discoverable. No OpenAPI,
  GraphQL SDL, AsyncAPI or MCP manifest is published on any EatStreet host.
- [Authorization server metadata](https://eatstreet.com/.well-known/oauth-authorization-server):
  RFC 8414 document. Issuer https://eatstreet.com; authorization endpoint
  https://eatstreet.com/authorize; token, introspection and revocation endpoints
  under https://eatstreet.com/api/v2/oauth/. PKCE S256 supported. Scopes:
  merchant_integration, customer, example.
- [JWKS](https://eatstreet.com/.well-known/jwks.json): RSA signing keys referenced
  by jwks_uri.

## Retired

- EatStreet Public API v1 (https://api.eatstreet.com/publicapi/v1) — restaurant
  search, menus, order placement and user management. Retired; every documented
  path returns 404.
- developers.eatstreet.com — the public API documentation host. Returns 404, though
  it is still advertised in the description of https://github.com/eatstreet.
